# License Atlas — README en español

[English](README.md) · [Licencia](LICENSE) · [Catálogo completo](docs/comparison.md) · [Cabeceras de lenguajes](docs/languages.md)

License Atlas es una referencia basada en SPDX para comparar licencias de software, documentación, fuentes, contenido y datos. Esta página ofrece un resumen en español; el README en inglés es la fuente canónica del contenido completo y de la terminología.

## Qué incluye

- Un catálogo práctico de 50 licencias y familias de licencias SPDX frecuentes.
- Comparaciones de uso comercial, modificación, redistribución, avisos, patentes y alcance copyleft.
- Ejemplos de cabeceras SPDX para 20 lenguajes de programación comunes.
- Una lista de comprobación para revisar dependencias y notas de compatibilidad.

## Cómo usarlo

Confirma el identificador y la versión exactos de SPDX, lee el texto completo de la licencia y conserva los avisos de copyright, licencia y atribución exigidos. Para decisiones comerciales o de alto riesgo, consulta asesoramiento jurídico profesional.
