# License Atlas — README in italiano

[English](README.md) · [Licenza](LICENSE) · [Catalogo completo](docs/comparison.md) · [Intestazioni dei linguaggi](docs/languages.md)

License Atlas è un riferimento basato su SPDX per confrontare le licenze di software, documentazione, caratteri, contenuti e dati. Questa pagina offre una panoramica in italiano; il README inglese è la fonte canonica per il contenuto e la terminologia completi.

## Cosa include

- Un catalogo pratico di 50 licenze e famiglie di licenze SPDX comuni.
- Confronti su uso commerciale, modifiche, redistribuzione, avvisi, brevetti e ambito copyleft.
- Esempi di intestazioni SPDX per 20 linguaggi di programmazione comuni.
- Checklist per la revisione delle dipendenze e note sulla compatibilità.

## Come usarlo

Verifica l’identificatore e la versione SPDX esatti, leggi il testo completo della licenza e conserva gli avvisi obbligatori di copyright, licenza e attribuzione. Per decisioni commerciali o ad alto rischio, richiedi una consulenza legale professionale.
