# License Atlas — README بالعربية

[English](README.md) · [الترخيص](LICENSE) · [الفهرس الكامل](docs/comparison.md) · [ترويسات لغات البرمجة](docs/languages.md)

License Atlas هو مرجع يعتمد على SPDX لمقارنة تراخيص البرمجيات والوثائق والخطوط والمحتوى والبيانات. تقدم هذه الصفحة ملخصًا باللغة العربية؛ ويظل README الإنجليزي المصدر الأساسي للمحتوى والمصطلحات الكاملة.

## ما الذي يتضمنه المشروع؟

- فهرس عملي يضم 50 ترخيصًا وعائلة تراخيص شائعة من SPDX.
- مقارنة الاستخدام التجاري والتعديل وإعادة التوزيع والإشعارات وبراءات الاختراع ونطاق copyleft.
- أمثلة لترويسات SPDX في 20 لغة برمجة شائعة.
- قائمة لمراجعة التبعيات وملاحظات حول التوافق.

## طريقة الاستخدام

تحقق من معرّف SPDX والإصدار بدقة، واقرأ نص الترخيص كاملًا، واحتفظ بإشعارات حقوق النشر والترخيص ونسبة الفضل المطلوبة. استشر مختصًا قانونيًا للقرارات التجارية أو عالية المخاطر.
