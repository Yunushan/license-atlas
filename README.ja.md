# License Atlas — 日本語 README

[English](README.md) · [ライセンス](LICENSE) · [完全なカタログ](docs/comparison.md) · [プログラミング言語のヘッダー](docs/languages.md)

License Atlas は、ソフトウェア、ドキュメント、フォント、コンテンツ、データのライセンスを比較するための SPDX ベースのリファレンスです。このページは日本語の概要です。完全な内容と用語については英語版 README を正本として参照してください。

## 内容

- よく使われる SPDX ライセンスとライセンスファミリー 50 件の実用的なカタログ。
- 商用利用、変更、再配布、通知、特許、copyleft の範囲に関する比較。
- 20 種類の一般的なプログラミング言語向け SPDX ファイルヘッダーの例。
- 依存関係の確認チェックリストと互換性に関する注意点。

## 使い方

正確な SPDX 識別子とバージョンを確認し、ライセンス全文を読み、必要な著作権・ライセンス・帰属表示を保持してください。商用または高リスクの判断では、専門家に相談してください。
