# License Atlas — README Bahasa Indonesia

[English](README.md) · [Lisensi](LICENSE) · [Katalog lengkap](docs/comparison.md) · [Header bahasa pemrograman](docs/languages.md)

License Atlas adalah referensi berbasis SPDX untuk membandingkan lisensi perangkat lunak, dokumentasi, font, konten, dan data. Halaman ini memberikan ringkasan dalam Bahasa Indonesia; README bahasa Inggris adalah sumber utama untuk isi dan istilah lengkap.

## Isi proyek

- Katalog praktis berisi 50 lisensi dan keluarga lisensi SPDX yang umum.
- Perbandingan penggunaan komersial, modifikasi, redistribusi, pemberitahuan, paten, dan cakupan copyleft.
- Contoh header SPDX untuk 20 bahasa pemrograman yang umum digunakan.
- Daftar periksa peninjauan dependensi dan catatan kompatibilitas.

## Cara menggunakan

Pastikan pengenal dan versi SPDX yang tepat, baca teks lisensi secara lengkap, dan pertahankan pemberitahuan hak cipta, lisensi, serta atribusi yang diwajibkan. Untuk keputusan komersial atau berisiko tinggi, mintalah nasihat hukum profesional.
