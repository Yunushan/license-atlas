# License Atlas — తెలుగు README

[English](README.md) · [లైసెన్స్](LICENSE) · [పూర్తి కేటలాగ్](docs/comparison.md) · [ప్రోగ్రామింగ్ భాషల హెడర్లు](docs/languages.md)

License Atlas అనేది సాఫ్ట్‌వేర్, డాక్యుమెంటేషన్, ఫాంట్లు, కంటెంట్ మరియు డేటా లైసెన్సులను పోల్చడానికి SPDX ఆధారిత రిఫరెన్స్. ఈ పేజీ తెలుగు సంక్షిప్త పరిచయం; పూర్తి కంటెంట్ మరియు పదజాలానికి ఆంగ్ల README ప్రధాన మూలం.

## ఇందులో ఏముంది

- 50 సాధారణ SPDX లైసెన్సులు మరియు లైసెన్స్ కుటుంబాల ప్రాయోగిక కేటలాగ్.
- వాణిజ్య వినియోగం, మార్పులు, పునర్వితరణ, నోటీసులు, పేటెంట్లు మరియు copyleft పరిధి పోలిక.
- 20 సాధారణ ప్రోగ్రామింగ్ భాషల కోసం SPDX ఫైల్ హెడర్ ఉదాహరణలు.
- డిపెండెన్సీ సమీక్ష చెక్‌లిస్ట్ మరియు అనుకూలత సూచనలు.

## ఉపయోగం

ఖచ్చితమైన SPDX గుర్తింపు మరియు సంస్కరణను నిర్ధారించండి, పూర్తి లైసెన్స్ పాఠ్యాన్ని చదవండి, అవసరమైన కాపీరైట్, లైసెన్స్ మరియు attribution నోటీసులను ఉంచండి. ముఖ్యమైన వాణిజ్య లేదా చట్టపరమైన నిర్ణయాలకు నిపుణుల సలహా పొందండి.
