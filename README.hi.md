License Atlas सॉफ़्टवेयर, दस्तावेज़, फ़ॉन्ट, सामग्री और डेटा लाइसेंस की तुलना के लिए SPDX-आधारित संदर्भ है। यह पृष्ठ हिन्दी में संक्षिप्त परिचय देता है; पूरी सामग्री और शब्दावली के लिए अंग्रेज़ी README आधिकारिक स्रोत है।

## इसमें क्या है

- 50 सामान्य SPDX लाइसेंस और लाइसेंस परिवारों का व्यावहारिक कैटलॉग।
- व्यावसायिक उपयोग, संशोधन, पुनर्वितरण, नोटिस, पेटेंट और copyleft दायरे की तुलना।
- 20 सामान्य प्रोग्रामिंग भाषाओं के लिए SPDX फ़ाइल हेडर उदाहरण।
- निर्भरता समीक्षा चेकलिस्ट और संगतता संबंधी सावधानियाँ।

## उपयोग

सटीक SPDX पहचानकर्ता और संस्करण जाँचें, पूरा लाइसेंस पढ़ें, और आवश्यक कॉपीराइट, लाइसेंस तथा attribution नोटिस सुरक्षित रखें। महत्वपूर्ण व्यावसायिक या कानूनी निर्णयों के लिए विशेषज्ञ सलाह लें।
