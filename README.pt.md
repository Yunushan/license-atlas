# License Atlas — README em português

[English](README.md) · [Licença](LICENSE) · [Catálogo completo](docs/comparison.md) · [Cabeçalhos de linguagens](docs/languages.md)

License Atlas é uma referência baseada em SPDX para comparar licenças de software, documentação, fontes, conteúdo e dados. Esta página oferece um resumo em português; o README em inglês é a fonte canônica do conteúdo completo e da terminologia.

## O que inclui

- Um catálogo prático de 50 licenças e famílias de licenças SPDX comuns.
- Comparações de uso comercial, modificação, redistribuição, avisos, patentes e escopo copyleft.
- Exemplos de cabeçalhos SPDX para 20 linguagens de programação comuns.
- Checklist de revisão de dependências e observações de compatibilidade.

## Como usar

Confirme o identificador e a versão exatos do SPDX, leia o texto completo da licença e preserve os avisos de copyright, licença e atribuição exigidos. Para decisões comerciais ou de alto risco, procure orientação jurídica profissional.
