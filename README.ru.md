# License Atlas — README на русском

[English](README.md) · [Лицензия](LICENSE) · [Полный каталог](docs/comparison.md) · [Заголовки языков программирования](docs/languages.md)

License Atlas — это справочный проект на основе SPDX для сравнения лицензий программного обеспечения, документации, шрифтов, контента и данных. На этой странице приведён краткий обзор на русском языке; английский README является основным источником полного содержания и терминологии.

## Что входит

- Практический каталог из 50 распространённых лицензий и семейств лицензий SPDX.
- Сравнение коммерческого использования, изменения, распространения, уведомлений, патентных положений и области copyleft.
- Примеры заголовков SPDX для 20 распространённых языков программирования.
- Контрольный список проверки зависимостей и замечания о совместимости.

## Использование

Проверьте точный идентификатор и версию SPDX, прочитайте полный текст лицензии и сохраните обязательные уведомления об авторских правах, лицензии и атрибуции. Для коммерческих решений и решений с высоким риском обратитесь к юристу.
