# Security policy

License Atlas is a documentation and reference project. It does not process user data, credentials, or network requests at runtime.

If you find a supply-chain, workflow, or repository-security issue, please avoid publishing sensitive details in a public issue. Submit a private [GitHub security advisory](https://github.com/Yunushan/license-atlas/security/advisories/new) and include a reproducible description, affected path or workflow, and any safe evidence needed to triage the issue.
