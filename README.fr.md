# License Atlas — README en français

[English](README.md) · [Licence](LICENSE) · [Catalogue complet](docs/comparison.md) · [En-têtes des langages](docs/languages.md)

License Atlas est une référence fondée sur SPDX pour comparer les licences de logiciels, de documentation, de polices, de contenus et de données. Cette page propose un résumé en français ; le README anglais reste la source de référence pour le contenu et la terminologie complets.

## Contenu

- Un catalogue pratique de 50 licences et familles de licences SPDX courantes.
- Des comparaisons concernant l’usage commercial, la modification, la redistribution, les avis, les brevets et la portée du copyleft.
- Des exemples d’en-têtes SPDX pour 20 langages de programmation courants.
- Une liste de contrôle pour examiner les dépendances et des remarques sur la compatibilité.

## Utilisation

Vérifiez l’identifiant et la version SPDX exacts, lisez le texte intégral de la licence et conservez les avis de copyright, de licence et d’attribution requis. Pour les décisions commerciales ou à risque élevé, demandez un avis juridique professionnel.
