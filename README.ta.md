## இதில் உள்ளவை

- பொதுவாகப் பயன்படுத்தப்படும் 50 SPDX உரிமங்கள் மற்றும் உரிமக் குடும்பங்களின் நடைமுறை பட்டியல்.
- வணிகப் பயன்பாடு, மாற்றம், மறுவிநியோகம், அறிவிப்புகள், காப்புரிமைகள் மற்றும் copyleft வரம்பின் ஒப்பீடு.
- 20 பொதுவான நிரலாக்க மொழிகளுக்கான SPDX கோப்பு தலைப்பு எடுத்துக்காட்டுகள்.
- சார்பு மதிப்பாய்வு சரிபார்ப்புப் பட்டியல் மற்றும் பொருந்தக்கூடிய குறிப்புகள்.

## பயன்படுத்துவது எப்படி

சரியான SPDX அடையாளத்தையும் பதிப்பையும் சரிபார்த்து, முழு உரிம உரையைப் படித்து, தேவையான பதிப்புரிமை, உரிமம் மற்றும் attribution அறிவிப்புகளைப் பாதுகாக்கவும். முக்கியமான வணிக அல்லது சட்ட முடிவுகளுக்கு நிபுணர் ஆலோசனையைப் பெறவும்.
