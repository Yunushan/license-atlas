# License Atlas — मराठी README

[English](README.md) · [परवाना](LICENSE) · [संपूर्ण कॅटलॉग](docs/comparison.md) · [प्रोग्रामिंग भाषा हेडर](docs/languages.md)

License Atlas हा सॉफ्टवेअर, दस्तऐवज, फॉन्ट, सामग्री आणि डेटाच्या परवान्यांची तुलना करण्यासाठी SPDX-आधारित संदर्भ आहे. या पानावर मराठीत संक्षिप्त माहिती दिली आहे; संपूर्ण मजकूर आणि संज्ञांसाठी इंग्रजी README हा मुख्य स्रोत आहे.

## काय समाविष्ट आहे

- 50 सामान्य SPDX परवाने आणि परवाना कुटुंबांचा व्यावहारिक कॅटलॉग।
- व्यावसायिक वापर, बदल, पुनर्वितरण, सूचना, पेटंट आणि copyleft व्याप्तीची तुलना।
- 20 सामान्य प्रोग्रामिंग भाषांसाठी SPDX फाइल हेडरची उदाहरणे।
- अवलंबित्व तपासणी यादी आणि सुसंगततेविषयी सूचना।

## वापर

अचूक SPDX ओळखकर्ता आणि आवृत्ती तपासा, संपूर्ण परवाना वाचा आणि आवश्यक कॉपीराइट, परवाना व attribution सूचना जतन करा. महत्त्वाच्या व्यावसायिक किंवा कायदेशीर निर्णयांसाठी तज्ज्ञांचा सल्ला घ्या.
