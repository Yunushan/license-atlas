# License Atlas — README tiếng Việt

[English](README.md) · [Giấy phép](LICENSE) · [Danh mục đầy đủ](docs/comparison.md) · [Header ngôn ngữ lập trình](docs/languages.md)

License Atlas là tài liệu tham khảo dựa trên SPDX để so sánh giấy phép phần mềm, tài liệu, phông chữ, nội dung và dữ liệu. Trang này cung cấp phần tổng quan bằng tiếng Việt; README tiếng Anh là nguồn chuẩn cho toàn bộ nội dung và thuật ngữ.

## Nội dung

- Danh mục thực tế gồm 50 giấy phép và nhóm giấy phép SPDX phổ biến.
- So sánh việc sử dụng thương mại, sửa đổi, phân phối lại, thông báo, bằng sáng chế và phạm vi copyleft.
- Ví dụ header SPDX cho 20 ngôn ngữ lập trình phổ biến.
- Danh sách kiểm tra khi xem xét dependency và ghi chú về khả năng tương thích.

## Cách sử dụng

Hãy xác nhận đúng mã định danh và phiên bản SPDX, đọc toàn bộ văn bản giấy phép, đồng thời giữ lại các thông báo bản quyền, giấy phép và ghi công bắt buộc. Với quyết định thương mại hoặc rủi ro cao, hãy tìm tư vấn pháp lý chuyên môn.
