# License Atlas — README auf Deutsch

[English](README.md) · [Lizenz](LICENSE) · [Vollständiger Katalog](docs/comparison.md) · [Header für Programmiersprachen](docs/languages.md)

License Atlas ist eine SPDX-basierte Referenz zum Vergleich von Lizenzen für Software, Dokumentation, Schriftarten, Inhalte und Daten. Diese Seite bietet eine deutsche Übersicht; das englische README ist die maßgebliche Quelle für den vollständigen Inhalt und die Terminologie.

## Inhalt

- Ein praktischer Katalog mit 50 verbreiteten SPDX-Lizenzen und Lizenzfamilien.
- Vergleiche zu kommerzieller Nutzung, Änderungen, Weitergabe, Hinweisen, Patenten und Copyleft-Umfang.
- Beispiele für SPDX-Datei-Header in 20 gängigen Programmiersprachen.
- Checkliste zur Abhängigkeitsprüfung und Hinweise zur Kompatibilität.

## Verwendung

Prüfe die genaue SPDX-Kennung und Version, lies den vollständigen Lizenztext und bewahre die erforderlichen Urheberrechts-, Lizenz- und Attributionshinweise auf. Für kommerzielle Entscheidungen oder Entscheidungen mit hohem Risiko solltest du professionellen Rechtsrat einholen.
