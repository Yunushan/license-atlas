# License Atlas — 简体中文 README

[English](README.md) · [许可证](LICENSE) · [完整目录](docs/comparison.md) · [编程语言标头](docs/languages.md)

License Atlas 是一个用于比较软件、文档、字体、内容和数据许可证的 SPDX 参考项目。本页提供简体中文概览；英文版 README 是完整内容和术语的规范来源。

## 项目内容

- 50 个常见 SPDX 许可证及许可证家族的实用目录。
- 关于商业使用、修改、再分发、通知、专利和 copyleft 范围的比较。
- 20 种常用编程语言的 SPDX 文件标头示例。
- 依赖审查清单和兼容性注意事项。

## 开始阅读

请先确认准确的 SPDX 标识符和版本，阅读完整许可证文本，并保留所需的版权、许可证和归属通知。对于高风险或商业决策，请寻求专业法律意见。
