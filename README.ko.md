# License Atlas — 한국어 README

[English](README.md) · [라이선스](LICENSE) · [전체 카탈로그](docs/comparison.md) · [프로그래밍 언어 헤더](docs/languages.md)

License Atlas는 소프트웨어, 문서, 글꼴, 콘텐츠 및 데이터 라이선스를 비교하기 위한 SPDX 기반 참고 자료입니다. 이 페이지는 한국어 요약을 제공하며, 전체 내용과 용어의 기준은 영어 README입니다.

## 포함 내용

- 자주 사용되는 SPDX 라이선스 및 라이선스 계열 50개의 실용적인 카탈로그.
- 상업적 사용, 수정, 재배포, 고지, 특허 및 copyleft 범위 비교.
- 20개 주요 프로그래밍 언어의 SPDX 파일 헤더 예시.
- 의존성 검토 체크리스트와 호환성 주의사항.

## 사용 방법

정확한 SPDX 식별자와 버전을 확인하고, 라이선스 전문을 읽으며, 필요한 저작권·라이선스·귀속 고지를 보존하세요. 상업적이거나 위험도가 높은 결정에는 전문 법률 자문을 받으세요.
