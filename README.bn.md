# License Atlas — বাংলা README

[English](README.md) · [লাইসেন্স](LICENSE) · [সম্পূর্ণ ক্যাটালগ](docs/comparison.md) · [প্রোগ্রামিং ভাষার হেডার](docs/languages.md)

License Atlas হলো সফটওয়্যার, ডকুমেন্টেশন, ফন্ট, কনটেন্ট ও ডেটার লাইসেন্স তুলনা করার একটি SPDX-ভিত্তিক রেফারেন্স। এই পাতায় বাংলায় সংক্ষিপ্ত পরিচয় দেওয়া হয়েছে; সম্পূর্ণ বিষয়বস্তু ও পরিভাষার জন্য ইংরেজি README-ই মূল উৎস।

## কী আছে

- ৫০টি প্রচলিত SPDX লাইসেন্স ও লাইসেন্স পরিবারের ব্যবহারিক ক্যাটালগ।
- বাণিজ্যিক ব্যবহার, পরিবর্তন, পুনর্বিতরণ, নোটিশ, পেটেন্ট ও copyleft পরিসরের তুলনা।
- ২০টি প্রচলিত প্রোগ্রামিং ভাষার SPDX ফাইল-হেডার উদাহরণ।
- নির্ভরতা পর্যালোচনা চেকলিস্ট ও সামঞ্জস্যসংক্রান্ত সতর্কতা।

## ব্যবহার

সঠিক SPDX শনাক্তকারী ও সংস্করণ যাচাই করুন, সম্পূর্ণ লাইসেন্স পড়ুন এবং প্রয়োজনীয় কপিরাইট, লাইসেন্স ও attribution নোটিশ সংরক্ষণ করুন। গুরুত্বপূর্ণ বাণিজ্যিক বা আইনি সিদ্ধান্তে পেশাদার পরামর্শ নিন।
